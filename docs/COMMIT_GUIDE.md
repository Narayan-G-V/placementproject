# Commit Guide & Strategy

To satisfy project requirements (minimum 15 genuine commits spread across team members), use this commit schedule:

## Commit Schedule
1. `docs: add initial project structure and README`
2. `feat(model): create User and Account model classes`
3. `feat(model): implement SavingsAccount and CurrentAccount subclasses`
4. `feat(model): add Transaction model class`
5. `feat(exceptions): create InsufficientBalanceException`
6. `feat(exceptions): create AccountNotFoundException and InvalidTransactionException`
7. `feat(dsa): implement custom TransactionStack data structure`
8. `feat(service): implement AuthService for PIN validation`
9. `feat(service): implement AccountService with HashMap storage`
10. `feat(service): implement TransactionService for deposit and withdrawal`
11. `feat(service): add fund transfer logic in TransactionService`
12. `feat(service): implement StatementService using custom TransactionStack`
13. `feat(util): add InputValidator and helper constants`
14. `feat(app): build interactive Scanner console menu in Main`
15. `fix(service): add try-catch error handling and account validation`
16. `docs: finalize inline comments and project documentation`
